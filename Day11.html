1. Introduction to Loops

A loop is used to execute the same block of code repeatedly until a specified condition becomes false.

Loops help reduce code repetition, improve readability, and make programs easier to maintain.

Without Loop With Loop
Writing the same statement many times. Write one loop and execute it multiple times.

2. Why Do We Use Loops?

  • Reduce code duplication
  • Execute repetitive tasks
  • Process arrays and strings
  • Improve readability
  • Save development time
  • Easy to maintain code

3. for Loop

The for loop is used when the number of iterations is already known.

Syntax
for(initialization; condition; increment/decrement){

    // code

}
Flow
  1. Initialization executes once.
  2. Condition is checked.
  3. Loop body executes.
  4. Increment/Decrement executes.
  5. Condition is checked again.
Example 1
for(let i = 1; i <= 5; i++){

    console.log(i);

}
Output
1
2
3
4
5
Example 2 : Print Even Numbers
for(let i = 2; i <= 20; i += 2){

    console.log(i);

}
Example 3 : Reverse Counting
for(let i = 10; i >= 1; i--){

    console.log(i);

}
Example 4 : Table of 5
for(let i = 1; i <= 10; i++){

    console.log("5 x " + i + " = " + (5*i));

}

4. while Loop

The while loop executes as long as the condition remains true.

Syntax
initialization;

while(condition){

    // code

    increment/decrement;

}
Example 1
let i = 1;

while(i <= 5){

    console.log(i);

    i++;

}
Example 2 : Even Numbers
let i = 2;

while(i <= 20){

    console.log(i);

    i += 2;

}
Example 3 : Countdown
let i = 10;

while(i >= 1){

    console.log(i);

    i--;

}

5. do...while Loop

The do...while loop executes the code block at least once, even if the condition is false.

Syntax
do{

    // code

}while(condition);
Example 1
let i = 1;

do{

    console.log(i);

    i++;

}while(i <= 5);
Output
1
2
3
4
5
Example 2
let i = 10;

do{

    console.log(i);

    i--;

}while(i >= 1);

The loop body executes once before checking the condition.

6. for...in Loop

The for...in loop is mainly used to iterate over the properties of an object.

Syntax
for(let key in object){

    // code

}
Example 1 : Object
let student = {

    name : "Awanish",

    age : 24,

    city : "Lucknow"

};

for(let key in student){

    console.log(key);

}
Example 2 : Key & Value
for(let key in student){

    console.log(key + " : " + student[key]);

}
Example 3 : Array Index
let numbers = [10,20,30,40];

for(let index in numbers){

    console.log(index);

}

Note: for...in returns keys (property names or indexes).

7. for...of Loop

The for...of loop is used to iterate over iterable objects like arrays, strings, maps and sets.

Syntax
for(let value of iterable){

    // code

}
Example 1 : Array
let marks = [80,85,90,95];

for(let value of marks){

    console.log(value);

}
Example 2 : String
let name = "JavaScript";

for(let ch of name){

    console.log(ch);

}
Example 3 : Sum of Array
let arr = [10,20,30];

let sum = 0;

for(let value of arr){

    sum += value;

}

console.log(sum);

Note: for...of returns actual values.

8. forEach() Method

The forEach() method executes a callback function once for each array element.

Syntax
array.forEach(function(value,index,array){

});
Example 1
let numbers = [10,20,30];

numbers.forEach(function(value){

    console.log(value);

});
Example 2 : Arrow Function
numbers.forEach((value)=>{

    console.log(value);

});
Example 3 : Index & Value
numbers.forEach((value,index)=>{

    console.log(index,value);

});
Example 4 : Square of Numbers
numbers.forEach((value)=>{

    console.log(value * value);

});

9. break Statement

The break statement immediately terminates the loop.

Example 1
for(let i = 1; i <= 10; i++){

    if(i == 6){

        break;

    }

    console.log(i);

}
Output
1
2
3
4
5

10. continue Statement

The continue statement skips the current iteration and moves to the next iteration.

Example 1
for(let i = 1; i <= 10; i++){

    if(i == 5){

        continue;

    }

    console.log(i);

}
Output
1
2
3
4
6
7
8
9
10

11. Nested Loops

A Nested Loop is a loop inside another loop. For every iteration of the outer loop, the inner loop executes completely.

Syntax
for(initialization; condition; increment){

    for(initialization; condition; increment){

        // code

    }

}
Example 1
for(let i = 1; i <= 3; i++){

    for(let j = 1; j <= 3; j++){

        console.log(i , j);

    }

}
Example 2 : Multiplication Table
for(let i = 1; i <= 5; i++){

    for(let j = 1; j <= 10; j++){

        console.log(i + " x " + j + " = " + (i*j));

    }

}
