1. Introduction to Functions

A function is a reusable block of code that performs a specific task. 

function greet(){

console.log("Welcome");

}
Functions help avoid code repetition.

2. Why Functions?

Without functions, the same code must be written repeatedly. 

console.log("Hello");

console.log("Hello");

console.log("Hello");

Using function: 

function sayHello(){

console.log("Hello");

}

sayHello();
sayHello();
sayHello();

3. Function Declaration

A normal function definition. 

function display(){

console.log("Function Called");

}
Syntax: function functionName(){ // code }

4. Function Calling

Functions execute only when called. 

function greet(){

console.log("Good Morning");

}

greet();

Good Morning

5. Function Parameters

Parameters receive values. 

function greet(name){

console.log("Hello " + name);

}

6. Function Arguments

Arguments are actual values passed. 

function greet(name){

console.log("Hello " + name);

}

greet("Awanish");

Hello Awanish

7. Return Statement

return sends a value back. 

function add(a,b){

return a+b;

}

let result=add(10,20);

console.log(result);

30

8. Function Expression

Function stored inside a variable. 

const greet=function(){

console.log("Hello");

};

greet();

9. Anonymous Function

Function without a name. 

let demo=function(){

console.log("Anonymous Function");

};
Mostly used as callback functions.

10. Arrow Function

Modern ES6 syntax. 

const add=(a,b)=>{

return a+b;

};

console.log(add(5,10));

15
Arrow functions are heavily used in React.js.

11. Default Parameters

Default parameters assign a default value if no argument is passed. 

function greet(name="Guest"){

console.log("Welcome "+name);

}

greet();

greet("Awanish");

Welcome Guest
Welcome Awanish
Default parameters were introduced in ES6.

12. Rest Parameters (...)

Rest parameters allow a function to accept any number of arguments. 

function sum(...numbers){

let total=0;

for(let num of numbers){

total+=num;

}

return total;

}

console.log(sum(10,20,30,40));

100

13. Callback Function

A callback is a function passed as an argument to another function. 

function greet(name){

console.log("Hello "+name);

}

function processUser(callback){

callback("Awanish");

}

processUser(greet);

Hello Awanish
Callbacks are widely used in JavaScript asynchronous programming.

14. Higher Order Functions

A Higher Order Function either accepts another function as a parameter or returns a function. 

function calculate(a,b,operation){

return operation(a,b);

}

function add(x,y){

return x+y;

}

console.log(calculate(10,20,add));

30

15. Immediately Invoked Function Expression (IIFE)

Runs immediately after it is defined. 

(function(){

console.log("IIFE Executed");

})();

IIFE Executed
Used to avoid polluting the global scope.

16. Recursive Function

A recursive function calls itself. 

function factorial(n){

if(n==1){

return 1;

}

return n*factorial(n-1);

}

console.log(factorial(5));

120

17. Nested Functions

A function declared inside another function. 

function outer(){

function inner(){

console.log("Inner Function");

}

inner();

}

outer();

Inner Function

18. Function Scope

Variables declared inside a function are accessible only within that function. 

function demo(){

let message="Hello";

console.log(message);

}

demo();

// console.log(message); // Error
Local variables cannot be accessed outside the function.

19. Function Hoisting

Function declarations are hoisted in JavaScript. 

greet();

function greet(){

console.log("Hello");

}

Hello
Only function declarations are hoisted, not function expressions.

20. Closures

A closure allows an inner function to access variables of its outer function even after the outer function has finished execution. 

function outer(){

let count=0;

return function(){

count++;

console.log(count);

}

}

let counter=outer();

counter();

counter();

counter();

1
2
3
Closures are one of the most important JavaScript interview topics.

Summary

  • Functions are reusable blocks of code.
  • Functions reduce code duplication.
  • Parameters receive values, while arguments pass values.
  • The return statement sends data back to the caller.
  • Arrow functions provide concise syntax and are heavily used in modern JavaScript and React.
  • Callbacks and Higher Order Functions are fundamental concepts for asynchronous programming.
  • Closures are among the most frequently asked JavaScript interview topics.
  • Understanding scope and hoisting helps avoid common programming errors.
