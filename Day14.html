1. What is DOM?

DOM stands for Document Object Model. It is a programming interface provided by browsers that allows JavaScript to access and manipulate HTML documents.

Whenever a web page loads, the browser converts the HTML document into a tree-like structure called the DOM Tree. JavaScript can use this tree to add, modify, delete, or update HTML elements dynamically.

DOM acts as a bridge between HTML and JavaScript. Without DOM, JavaScript cannot modify webpage content.

28. Introduction to Events

Events are actions performed by the user or browser.

Examples include:

  • Click
  • Double Click
  • Mouse Over
  • Keyboard Press
  • Submit
  • Resize
JavaScript responds to user actions through events.

29. onclick Event

The onclick event executes when a user clicks an element.

30. addEventListener()

The recommended way to attach events.

Summary

  • DOM stands for Document Object Model.
  • JavaScript uses the DOM to access and manipulate HTML elements.
  • Elements can be selected using ID, class, tag name, or CSS selectors.
  • DOM allows changing content, styles, attributes, and structure dynamically.
  • Events make web pages interactive by responding to user actions.
  • addEventListener() is the preferred way to handle events.
  • Event Bubbling, Capturing, and Delegation are essential interview topics.
  • Strong DOM knowledge is the foundation for learning React.js and modern frontend development.
