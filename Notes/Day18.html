React Router v6 – Introduction

React Router is the standard routing library for React. It enables navigation between different views/components in a Single Page Application (SPA) without refreshing the page.

📌 Install: npm install react-router-dom
import { BrowserRouter, Routes, Route } from "react-router-dom";

function App() {
  return (
    <BrowserRouter>
      <Routes>
        <Route path="/" element={<Home />} />
        <Route path="/about" element={<About />} />
      </Routes>
    </BrowserRouter>
  );
}

BrowserRouter

BrowserRouter is the recommended router for web applications. It uses the HTML5 history API to keep the UI in sync with the URL.

✅ Wraps the entire app – usually placed in main.jsx or App.jsx.

Routes & Route

Routes is a container for multiple Route components. Each Route defines a path and the component to render when the path matches.

<Routes>
  <Route path="/" element={<Home />} />
  <Route path="/products" element={<Products />} />
  <Route path="/contact" element={<Contact />} />
</Routes>

Link & NavLink

Link is used for navigation between routes without refreshing the page. NavLink extends Link and adds styling attributes when the route is active.

import { Link, NavLink } from "react-router-dom";

<Link to="/">Home</Link>
<NavLink to="/about" className={({ isActive }) => isActive ? "active-link" : ""}>About</NavLink>
🧭 NavLink automatically applies active class when the route matches.

useNavigate Hook

useNavigate provides programmatic navigation – useful after form submissions, login, or button clicks.

import { useNavigate } from "react-router-dom";

function Login() {
  const navigate = useNavigate();
  const handleLogin = () => {
    // ... auth logic
    navigate("/dashboard");
  };
  return <button onClick={handleLogin}>Login</button>;
}

useParams – Dynamic Routes

useParams returns an object of key/value pairs from the URL parameters. Ideal for detail pages (e.g., /product/:id).

// Route definition
<Route path="/product/:id" element={<ProductDetail />} />

// In ProductDetail component
import { useParams } from "react-router-dom";

function ProductDetail() {
  const { id } = useParams();
  return <h3>Product ID: {id}</h3>;
}
🆔 Visiting /product/42 renders "Product ID: 42"

Nested Routes

Nested routes allow you to compose layouts where a parent component renders child routes using Outlet.

<Route path="/dashboard" element={<Dashboard />}>
  <Route path="profile" element={<Profile />} />
  <Route path="settings" element={<Settings />} />
</Route>

// In Dashboard.jsx
import { Outlet } from "react-router-dom";
function Dashboard() {
  return (
    <div>
      <h2>Dashboard</h2>
      <Outlet /> {/* child routes render here */}
    </div>
  );
}

Axios – HTTP Client

Axios is a promise-based HTTP client that works in the browser and Node.js. It simplifies making API calls with features like interceptors, automatic JSON transformation, and request cancellation.

📦 Install: npm install axios
import axios from "axios";

// GET request
axios.get("https://api.example.com/users")
  .then(response => console.log(response.data))
  .catch(error => console.error(error));

Axios – GET Request

async function fetchUsers() {
  try {
    const response = await axios.get("https://jsonplaceholder.typicode.com/users");
    console.log(response.data);
  } catch (error) {
    console.error("Error fetching users:", error);
  }
}
✅ response.data contains the actual data from the API.

Axios – POST Request

async function createUser(userData) {
  try {
    const response = await axios.post("https://api.example.com/users", userData);
    console.log("User created:", response.data);
  } catch (error) {
    console.error("Error creating user:", error);
  }
}

Axios – PUT & DELETE

// PUT – update existing resource
await axios.put(`https://api.example.com/users/${id}`, updatedData);

// DELETE – remove resource
await axios.delete(`https://api.example.com/users/${id}`);
🔄 Always use try/catch or .catch() to handle errors gracefully.

Async/Await & Error Handling

Using async/await makes asynchronous code more readable. Combine with try/catch for robust error handling.

async function fetchData() {
  try {
    const res = await axios.get("/api/data");
    setData(res.data);
  } catch (err) {
    if (err.response) {
      // server responded with a status other than 2xx
      setError(`Server error: ${err.response.status}`);
    } else if (err.request) {
      // request was made but no response
      setError("No response from server");
    } else {
      setError("Request failed");
    }
  }
}

Loading & Error States

Always manage loading, error and data states when making API calls to improve user experience.

function UsersList() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState(null);

  useEffect(() => {
    axios.get("/api/users")
      .then(res => { setUsers(res.data); setLoading(false); })
      .catch(err => { setError(err.message); setLoading(false); });
  }, []);

  if (loading) return <p>Loading...</p>;
  if (error) return <p className="text-danger">Error: {error}</p>;
  return <ul>{users.map(u => <li key={u.id}>{u.name}</li>)}</ul>;
}
