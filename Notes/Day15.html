Introduction to MongoDB

MongoDB is a popular NoSQL (Not Only SQL) database used to store data in the form of documents instead of tables. Unlike traditional relational databases (MySQL, Oracle, SQL Server), MongoDB stores data in BSON (Binary JSON) format, which makes it flexible and easy to work with modern web applications.

MongoDB was developed by MongoDB Inc. and is one of the most widely used databases in MERN Stack (MongoDB, Express.js, React.js, Node.js).

Why MongoDB?

MongoDB is preferred because it is fast, flexible, scalable, and schema-less.

Feature Description
Schema-less No fixed table structure is required.
JSON Based Stores data in JSON-like documents.
High Performance Fast read and write operations.
Scalable Supports Horizontal Scaling (Sharding).
Easy to Learn Simple query syntax.
Flexible Different documents can have different fields.

Open Command Prompt and run the following commands. 

mongod --version

mongosh
If MongoDB is installed correctly, the Mongo Shell will start successfully.
If you get 'mongod' is not recognized... then add the MongoDB bin folder to the Windows Environment Variables (PATH).

1. What is CRUD?

CRUD stands for the four basic database operations performed on data.

Letter Meaning
C Create (Insert Data)
R Read (Retrieve Data)
U Update (Modify Data)
D Delete (Remove Data)
Every MongoDB application uses CRUD operations. CRUD is one of the most important interview topics.

2. insertOne()

The insertOne() method inserts a single document into a collection. 

db.student.insertOne({

name:"Awanish",

age:22,

course:"B.Tech"

});
Document Inserted Successfully
If the collection does not exist, MongoDB automatically creates it.

3. insertMany()

The insertMany() method inserts multiple documents at once. 

db.student.insertMany([

{

name:"Rahul",

age:21,

course:"BCA"

},

{

name:"Ravi",

age:23,

course:"MCA"

},

{

name:"Priya",

age:20,

course:"B.Tech"

}

]);
3 Documents Inserted
insertMany() is faster than inserting documents one by one.

4. Read Documents

To retrieve data from MongoDB we use the find() and findOne() methods.

  • find()
  • findOne()
Read operation means fetching data from the database.

5. find()

The find() method returns all matching documents. 

db.student.find();
Returns every document present in the student collection.

6. findOne()

Returns only the first matching document. 

db.student.findOne();
Returns the first document only.

7. pretty()

The pretty() method displays documents in a readable format. 

db.student.find().pretty();
Documents are displayed with proper indentation.
Useful while learning MongoDB in the shell.

8. Finding Specific Documents

You can search documents by providing a condition. 

db.student.find({

name:"Rahul"

});
Returns all documents whose name is Rahul.

9. Finding Multiple Conditions

You can search using more than one field. 

db.student.find({

name:"Rahul",

age:21

});
Returns only documents where both conditions match.
MongoDB uses AND logic when multiple fields are specified.

10. Find by _id

Every MongoDB document contains a unique _id field. 

db.student.find({

_id:ObjectId("6863e4f2a1b2c3d4e5f6a11")

});
The _id uniquely identifies every document in a collection.

11. Projection

Projection is used to display only the required fields from a document. 

db.student.find(
{},
{
name:1,
age:1
}
);
Displays only the name and age fields.
1 → Include Field 0 → Exclude Field

12. Excluding Fields

Use 0 to exclude a field. 

db.student.find(
{},
{
course:0
}
);
Returns all fields except course.
You cannot mix inclusion (1) and exclusion (0) except for the _id field.

13. Comparison Operators

Comparison operators compare field values.

Operator Description
$eqEqual To
$gtGreater Than
$gteGreater Than or Equal To
$ltLess Than
$lteLess Than or Equal To
$neNot Equal To
$inMatch Any Value
$ninNot Match Any Value

14. Using $gt

Find students whose age is greater than 21. 

db.student.find({

age:{
$gt:21
}

});
Returns all students whose age is greater than 21.

15. Using $gte

Find students whose age is greater than or equal to 22. 

db.student.find({

age:{
$gte:22
}

});

16. Using $lt and $lte

Find students whose age is less than 22. 

db.student.find({

age:{
$lt:22
}

});

Less than or equal to: 

db.student.find({

age:{
$lte:22
}

});

17. Using $ne

Find all students except Rahul. 

db.student.find({

name:{
$ne:"Rahul"
}

});
Returns every document except Rahul.

18. Using $in and $nin

Find students whose course is either BCA or MCA. 

db.student.find({

course:{
$in:["BCA","MCA"]
}

});

Exclude BCA and MCA students. 

db.student.find({

course:{
$nin:["BCA","MCA"]
}

});

19. Logical Operators

Logical operators combine multiple conditions.

Operator Description
$andBoth conditions must be true
$orAny one condition must be true
$notNegates a condition
$norNeither condition should be true

20. Using $and and $or

Students whose age is greater than 20 and course is B.Tech. 

db.student.find({

$and:[

{age:{$gt:20}},

{course:"B.Tech"}

]

});

Students whose course is BCA or MCA. 

db.student.find({

$or:[

{course:"BCA"},

{course:"MCA"}

]

});
$and → All conditions must be true. $or → Any one condition can be true.

21. updateOne()

Updates the first matching document. 

db.student.updateOne(

{name:"Rahul"},

{

$set:{
age:25
}

}

);
Rahul's age becomes 25.
Always use $set when updating fields.

22. updateMany()

Updates all matching documents. 

db.student.updateMany(

{course:"BCA"},

{

$set:{

course:"BCA Graduate"

}

}

);
All BCA students are updated.

23. replaceOne()

The replaceOne() method replaces an entire document except the _id field. 

db.student.replaceOne(

{name:"Rahul"},

{

name:"Rahul",

age:24,

course:"MCA",

city:"Delhi"

}

);
Unlike updateOne(), replaceOne() replaces the complete document.

24. deleteOne()

Deletes the first matching document. 

db.student.deleteOne({

name:"Rahul"

});
One document deleted successfully.

25. deleteMany()

Deletes all matching documents. 

db.student.deleteMany({

course:"BCA"

});
All BCA student documents deleted.
Use deleteMany() carefully because multiple documents may be removed.

26. sort()

The sort() method sorts documents.

Ascending Order
db.student.find().sort({

age:1

});
Descending Order
db.student.find().sort({

age:-1

});
1 → Ascending -1 → Descending

27. limit()

Limits the number of returned documents. 

db.student.find().limit(5);
Returns only the first five documents.

28. skip()

Skips the specified number of documents. 

db.student.find().skip(3);
Skips the first three documents.

29. Combining sort(), limit() and skip()

These methods are commonly used together for pagination. 

db.student.find()

.sort({age:-1})

.skip(5)

.limit(5);
Returns the next five highest-age students after skipping the first five.
Very common in web applications for pagination.

30. countDocuments()

Returns the total number of matching documents. 

db.student.countDocuments();

Count only B.Tech students. 

db.student.countDocuments({

course:"B.Tech"

});
Displays the total number of matching documents.

31. distinct()

Returns unique values of a field. 

db.student.distinct("course");
["BCA","B.Tech","MCA"]
Useful for finding unique categories or values.

32. Complete CRUD Example

A simple CRUD workflow. 

// Insert

db.student.insertOne({

name:"Awanish",

age:22,

course:"B.Tech"

});

// Read

db.student.find();

// Update

db.student.updateOne(

{name:"Awanish"},

{

$set:{

age:23

}

}

);

// Delete

db.student.deleteOne({

name:"Awanish"

});
Most beginner interview questions are based on this CRUD flow.

Summary

  • CRUD stands for Create, Read, Update, and Delete.
  • insertOne() and insertMany() are used to insert documents.
  • find() and findOne() retrieve documents from a collection.
  • Projection helps return only the required fields.
  • Comparison and logical operators are used to filter data.
  • updateOne(), updateMany(), and replaceOne() modify documents.
  • deleteOne() and deleteMany() remove documents.
  • sort(), limit(), and skip() are commonly used for pagination.
  • countDocuments() counts matching documents, while distinct() returns unique values.
  • Mastering CRUD operations is the foundation for learning MongoDB Aggregation, Indexing, and Mongoose.
