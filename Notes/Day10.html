1. Arithmetic Operators

Used for mathematical calculations.

let a=10,b=3;\nconsole.log(a+b,a-b,a*b,a/b,a%b,a**b);

2. Assignment Operators

Assign values.

let x=5; x+=2; x*=3;

3. Comparison Operators

Compare two values.

console.log(10>5,10=='10',10==='10');

4. Logical Operators

&& || !

let age=20; console.log(age>=18 && age<60);

5. Bitwise Operators

Bit level operations.

console.log(5 & 1);

6. Ternary Operator

Short if else.

let msg=age>=18?'Adult':'Minor';

7. Nullish Coalescing

Default only for null/undefined.

let name=null; console.log(name ?? 'Guest');

8. Spread & Rest

Expand/collect values.

let a=[1,2]; let b=[...a,3];

9. Operator Precedence

Execution order.

console.log(2+3*4);

10. if Statement

Single condition.

if(age>=18){console.log('Eligible');}

11. if else

Two-way selection.

if(age>=18){} else {}

12. else if Ladder

Multiple conditions.

if(m>90){} else if(m>75){}

13. Nested if

if inside if.

if(a>0){if(a<10){}}

14. switch

Multiple choices.

switch(day){case 1:break;default:;}

15. Truthy & Falsy

Falsy: false,0,'',null,undefined,NaN

if(value){console.log('Truthy');}
