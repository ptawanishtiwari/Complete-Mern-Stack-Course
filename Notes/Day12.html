1. Introduction to Arrays

An Array is a special variable that can store multiple values in a single variable. 

let numbers = [10,20,30,40,50];
Output 
[10,20,30,40,50]
Remember: Arrays are zero-indexed. The first element starts from index 0.

2. Why Do We Need Arrays?

Suppose you want to store marks of 100 students. Without arrays you need 

let s1=90;
let s2=80;
let s3=75;
let s4=95;
...

Using arrays, 

let marks=[90,80,75,95];
Arrays reduce code duplication and make looping very easy.

3. Creating Arrays

There are multiple ways to create arrays.

Method 1
let arr=[1,2,3,4];
Method 2
let fruits=new Array("Apple","Banana","Mango");
Method 3
const names=["Aman","Rahul","Rohit"];
Square brackets [] are the most commonly used method.

let city=["Delhi","Lucknow","Kanpur"];

city[1]="Mumbai";

let numbers=[10,20,30,40,50];

length returns total number of elements.

10. push()

push() adds an element at the end of an array. 

let fruits=["Apple","Banana"];

fruits.push("Orange");

console.log(fruits);

["Apple","Banana","Orange"]
Interview Question: Difference between push() and unshift()? push() inserts at end. unshift() inserts at beginning.

11. pop()

The pop() method removes the last element from an array. 

let fruits=["Apple","Banana","Orange"];

fruits.pop();

console.log(fruits);

["Apple","Banana"]
Returns the removed element.

12. shift()

shift() removes the first element. 

let arr=[10,20,30,40];

arr.shift();

console.log(arr);

[20,30,40]

13. unshift()

Adds elements at the beginning. 

let arr=[20,30];

arr.unshift(10);

console.log(arr);

[10,20,30]
push() → End unshift() → Beginning

14. splice()

Used to add, remove or replace elements. 

let arr=[10,20,30,40];

arr.splice(2,1);

console.log(arr);

[10,20,40]
Add Element
let arr=[10,20,40];

arr.splice(2,0,30);

console.log(arr);

[10,20,30,40]

15. slice()

Returns a portion of an array without changing the original array. 

let arr=[10,20,30,40,50];

console.log(arr.slice(1,4));

[20,30,40]

16. concat()

Combines two or more arrays. 

let a=[1,2];

let b=[3,4];

console.log(a.concat(b));

[1,2,3,4]

17. join()

Converts array into string. 

let arr=["HTML","CSS","JS"];

console.log(arr.join("-"));

HTML-CSS-JS

18. includes()

Checks whether an element exists. 

let arr=["Java","Python","JavaScript"];

console.log(arr.includes("Python"));

console.log(arr.includes("PHP"));

true
false

19. indexOf()

Returns first occurrence index. 

let arr=["A","B","C","B"];

console.log(arr.indexOf("B"));

1

20. lastIndexOf()

Returns last occurrence index. 

let arr=["A","B","C","B"];

console.log(arr.lastIndexOf("B"));

3

21. reverse()

Reverses an array. 

let arr=[1,2,3,4];

arr.reverse();

console.log(arr);

[4,3,2,1]

22. sort()

Sorts array elements. 

let arr=[5,1,8,3];

arr.sort();

console.log(arr);

[1,3,5,8]
For numbers always use compare function. 
arr.sort((a,b)=>a-b);

23. find()

Returns first matching element. 

let arr=[10,20,30,40];

let result=arr.find(x=>x>25);

console.log(result);

30

24. findIndex()

Returns index of first matching element. 

let arr=[10,20,30,40];

console.log(arr.findIndex(x=>x>25));

2

25. filter()

Returns all matching elements. 

let arr=[10,15,20,25,30];

let even=arr.filter(x=>x%2==0);

console.log(even);

[10,20,30]
Interview Difference find() → Returns first matching value. filter() → Returns all matching values.

unshift()Add at beginning
splice()Add/Remove elements
slice()Extract portion
concat()Merge arrays
join()Convert into string
includes()Check existence
indexOf()Find first index
lastIndexOf()Find last index
reverse()Reverse array
sort()Sort array
find()Return first matching element
findIndex()Return first matching index
filter()Return all matching elements
map()Create transformed array
reduce()Reduce into one value
every()All elements satisfy condition
some()At least one satisfies condition
flat()Flatten nested arrays
flatMap()Map + Flat
fill()Fill values
copyWithin()Copy elements internally
Array.from()Create array from iterable
Array.of()Create array from arguments
Array.isArray()Check if value is array
at()Access using positive/negative index

Summary

  • Arrays store multiple values in one variable.
  • Array indexing starts from 0.
  • Arrays can contain any type of data.
  • JavaScript provides many built-in methods for array manipulation.
  • Methods like map(), filter(), and reduce() are frequently asked in interviews.
  • Practice array questions regularly because they are one of the most important JavaScript interview topics.
