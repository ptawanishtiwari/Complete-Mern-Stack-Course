Introduction to Backend Development

Backend Development refers to the server-side logic, database interactions, authentication, and API development that powers web applications. While the frontend handles what users see, the backend handles data processing, storage, and business logic.

🎯 Backend technologies include Node.js, Python (Django/Flask), Java (Spring Boot), PHP, Ruby on Rails, etc.
FrontendBackend
UI/UX, user interactionServer logic, databases
Runs in browserRuns on server
HTML, CSS, JavaScript, ReactNode.js, Python, Java, etc.
Handles presentationHandles data & business logic
✅ In the MERN stack, Node.js serves as the backend runtime environment.

Introduction to Node.js

Node.js is an open-source, cross-platform JavaScript runtime environment that executes JavaScript code outside a web browser. It's built on Chrome's V8 JavaScript engine and is widely used for building scalable network applications.

FeatureDescription
Runtime EnvironmentExecutes JavaScript on the server
Event-DrivenNon-blocking, asynchronous I/O
NPMLargest ecosystem of open-source libraries
Single-ThreadedUses event loop for concurrency
Cross-PlatformWorks on Windows, Linux, macOS
📌 Node.js is not a programming language; it's a runtime for JavaScript.

NPM – Node Package Manager

NPM is the default package manager for Node.js. It allows developers to install, share, and manage dependencies (libraries, frameworks, tools) for their projects.

// Install a package globally
npm install -g nodemon

// Install a package locally (project)
npm install express

// Install as development dependency
npm install --save-dev nodemon

// Uninstall a package
npm uninstall express
📦 package.json tracks all dependencies and scripts for your project.

Writing Your First Node.js Program

Let's create a simple Node.js script that prints a message to the console.

// app.js
console.log("Hello, Node.js!");

// Simple function
const greeting = (name) => {
  return `Welcome, ${name}!`;
};

console.log(greeting("Developer"));

// Using built-in modules
const os = require('os');
console.log("Platform:", os.platform());
console.log("CPU Cores:", os.cpus().length);
💻 Run the program using: node app.js
$ node app.js
Hello, Node.js!
Welcome, Developer!
Platform: win32
CPU Cores: 8

Installing Nodemon

Nodemon is a utility that monitors changes in your source code and automatically restarts the Node.js server. It's an essential tool for development.

🟣 Purple Theme: Nodemon makes development faster by eliminating the need to manually restart the server.
// Install globally (recommended)
npm install -g nodemon

// Install as dev dependency
npm install --save-dev nodemon
✅ After installation, you can use nodemon instead of node.

Using Nodemon

// Instead of:
node app.js

// Use:
nodemon app.js

// If you have a script in package.json
"scripts": {
  "start": "node app.js",
  "dev": "nodemon app.js"
}

// Then run:
npm run dev
$ nodemon app.js
[nodemon] 3.0.1
[nodemon] to restart at any time, enter `rs`
[nodemon] watching path(s): *.*
[nodemon] watching extensions: js,mjs,cjs,json
[nodemon] starting `node app.js`
Hello, Node.js!
[nodemon] clean exit - waiting for changes before restart
🟣 Nodemon watches all files in the project and restarts when changes are detected.

package.json Scripts

You can define custom scripts in package.json to simplify running commands.

{
  "name": "node-backend",
  "version": "1.0.0",
  "scripts": {
    "start": "node app.js",
    "dev": "nodemon app.js",
    "test": "echo 'No tests specified'",
    "lint": "eslint ."
  },
  "devDependencies": {
    "nodemon": "^3.0.1"
  }
}
🟣 Run scripts with npm run script-name (e.g., npm run dev)

Creating a Simple HTTP Server

Node.js comes with a built-in http module to create web servers.

// server.js
const http = require('http');

const server = http.createServer((req, res) => {
  res.writeHead(200, { 'Content-Type': 'text/plain' });
  res.end('Hello from Node.js Server!');
});

const PORT = 3000;
server.listen(PORT, () => {
  console.log(`Server running on http://localhost:${PORT}`);
});
$ nodemon server.js
[nodemon] starting `node server.js`
Server running on http://localhost:3000
[nodemon] clean exit - waiting for changes before restart
🟣 Visit http://localhost:3000 in your browser to see the response.

Best Practices

  • Use Nodemon only in development (install with --save-dev).
  • Always include a start script in package.json.
  • Use environment variables for configuration (e.g., PORT).
  • Ignore node_modules in version control (add to .gitignore).
  • Keep dependencies updated using npm update.
  • Use npm init to create a package.json file.
  • Use --save-dev for development-only packages.
🟣 Pro Tip: Add "type": "module" in package.json to use ES Modules.
