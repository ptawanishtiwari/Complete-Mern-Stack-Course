Props (Properties) in React

Props (short for properties) are read-only inputs that allow data to be passed from a parent component to a child component. They make components dynamic and reusable.

Props are immutable – a child component cannot modify the props it receives.
// Parent component function App() {
  const userName = "Aisha";
  return <Greeting name={userName} role="Admin" />;
}

// Child component
function Greeting(props) {
  return <h3>Hello {props.name} – {props.role}</h3>;
}
✅ Output: Hello Aisha – Admin

Destructuring Props

Instead of using props.name, we can destructure props directly in the function signature for cleaner code.

function Greeting({ name, role }) {
  return <h3>Hello {name} – {role}</h3>;
}
✅ Cleaner, more readable.

The children Prop

children is a special prop that lets you pass elements/components between the opening and closing tags of a component.

function Card({ children, title }) {
  return (
    <div className="card p-3">
      <h5>{title}</h5>
      <div>{children}</div>
    </div>
  );
}

// Usage
<Card title="Welcome">
  <p>This is the content inside the card.</p>
</Card>
🧩 children make components highly flexible (layout components, wrappers, etc.)

useState Hook

useState is a React Hook that lets you add state to functional components. It returns an array with two values: the current state and a function to update it.

import { useState } from "react";

function Counter() {
  const [count, setCount] = useState(0); // initial value 0
  return (
    <div>
      <p>Count: {count}</p>
      <button onClick={() => setCount(count + 1)}>Increment</button>
    </div>
  );
}
🔄 Each click updates the state and re‑renders the component.

Functional Updates (useState)

When the new state depends on the previous state, it's safer to use the functional update form.

setCount(prev => prev + 1);
⚡ Prevents race conditions when multiple updates are batched.

useEffect Hook

useEffect lets you perform side effects in function components: data fetching, subscriptions, timers, DOM manipulations, etc.

import { useEffect, useState } from "react";

function Timer() {
  const [seconds, setSeconds] = useState(0);

  useEffect(() => {
    const interval = setInterval(() => {
      setSeconds(s => s + 1);
    }, 1000);
    return () => clearInterval(interval); // cleanup
  }, []); // empty dependency array → runs once

  return <p>Timer: {seconds}s</p>;
}
⏱️ The timer increments every second. Cleanup prevents memory leaks.

useEffect – Dependency Array

Dependency arrayEffect runs
useEffect(fn, [])Once after initial render (mount)
useEffect(fn) (no array)After every render
useEffect(fn, [dep1, dep2])When dep1 or dep2 changes
🧠 Always specify dependencies to avoid infinite loops or unnecessary re‑runs.

Cleanup Function in useEffect

The function returned from useEffect is executed when the component unmounts or before the next effect runs. Used for cleaning up subscriptions, timers, event listeners, etc.

useEffect(() => {
  const handleResize = () => console.log("resized");
  window.addEventListener("resize", handleResize);
  return () => {
    window.removeEventListener("resize", handleResize);
  };
}, []);

Combined Example: Props + useState + useEffect

This mini‑app demonstrates all three concepts together.

📦 User Profile (with fetch)

👤 User: Alex

📧 Email: alex@dev.com

⏳ Timer (useEffect): 0s

(Simulated React behaviour – click buttons to see state updates)

function UserProfile({ userId }) {
  const [user, setUser] = useState(null);
  const [timer, setTimer] = useState(0);

  useEffect(() => {
    fetch(`/api/user/${userId}`)
      .then(res => res.json())
      .then(data => setUser(data));
  }, [userId]);

  useEffect(() => {
    const interval = setInterval(() => {
      setTimer(t => t + 1);
    }, 1000);
    return () => clearInterval(interval);
  }, []);

  if (!user) return <p>Loading...</p>;
  return (
    <div>
      <h5>{user.name}</h5>
      <p>{user.email}</p>
      <p>Timer: {timer}s</p>
    </div>
  );
}
