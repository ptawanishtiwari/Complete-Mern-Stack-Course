Introduction to MongoDB

MongoDB is a popular NoSQL document database that stores data in flexible, JSON-like documents with dynamic schemas. It's designed for scalability, high performance, and ease of development.

🟣 Purple Theme: MongoDB is the "M" in the MERN stack and is the preferred database for Node.js applications.
SQL (MySQL)NoSQL (MongoDB)
TablesCollections
RowsDocuments
ColumnsFields
Fixed SchemaDynamic Schema
RelationshipsEmbedded Documents
✅ MongoDB stores data in BSON (Binary JSON) format, making it natural for JavaScript applications.

Option 1: Install MongoDB Locally

🚀 MongoDB Atlas is the easiest way to get started and is free for development!

MongoDB Atlas Setup Guide

Follow these steps to set up MongoDB Atlas:

  1. Go to MongoDB Atlas and sign up.
  2. Create a free cluster (M0 tier).
  3. Set up database access: create a username and password.
  4. Set up network access: allow access from anywhere (0.0.0.0/0) or your IP.
  5. Get your connection string:
    mongodb+srv://<username>:<password>@cluster0.xxxxx.mongodb.net/<dbname>?retryWrites=true&w=majority
  6. Copy the connection string and keep it secure.
🔒 Never commit your connection string to version control! Use environment variables.

Connecting Node.js to MongoDB

We'll use the native MongoDB driver or Mongoose to connect to the database.

// Using native MongoDB driver
npm install mongodb

const { MongoClient } = require('mongodb');
const uri = process.env.MONGODB_URI;
const client = new MongoClient(uri);

async function connect() {
  try {
    await client.connect();
    console.log('Connected to MongoDB');
    const database = client.db('myDatabase');
    return database;
  } catch (error) {
    console.error('Connection error:', error);
  }
}

connect();
✅ The native driver gives you full control but requires more boilerplate code.

Introduction to Mongoose

Mongoose is an Object Data Modeling (ODM) library for MongoDB and Node.js. It provides a schema-based solution to model your application data, built-in type casting, validation, query building, and business logic hooks.

🟣 Mongoose is the most popular ODM for MongoDB and is widely used in the MERN stack.
// Install Mongoose
npm install mongoose

const mongoose = require('mongoose');

// Connect to MongoDB
mongoose.connect(process.env.MONGODB_URI, {
  useNewUrlParser: true,
  useUnifiedTopology: true
});

const db = mongoose.connection;
db.on('connected', () => {
  console.log('MongoDB connected successfully');
});
db.on('error', (err) => {
  console.error('MongoDB connection error:', err);
});
$ node server.js
MongoDB connected successfully

Mongoose Schema

A Schema defines the structure of documents in a collection. It specifies the fields, their types, validations, and default values.

const mongoose = require('mongoose');

// Define a schema for User
const userSchema = new mongoose.Schema({
  name: {
    type: String,
    required: [true, 'Name is required'],
    trim: true,
    minlength: [2, 'Name must be at least 2 characters']
  },
  email: {
    type: String,
    required: [true, 'Email is required'],
    unique: true,
    trim: true,
    lowercase: true,
    match: [/^\S+@\S+\.\S+$/, 'Please enter a valid email']
  },
  age: {
    type: Number,
    min: [18, 'Age must be at least 18'],
    max: [100, 'Age must be at most 100']
  },
  isActive: {
    type: Boolean,
    default: true
  },
  createdAt: {
    type: Date,
    default: Date.now
  }
});

// Add timestamps automatically
const productSchema = new mongoose.Schema({
  name: { type: String, required: true },
  price: { type: Number, required: true, min: 0 },
  category: String,
  inStock: { type: Boolean, default: true }
}, { timestamps: true }); // Adds createdAt and updatedAt

🟣 Common Schema Types: String, Number, Boolean, Date, Array, ObjectId, Mixed

Mongoose Model

A Model is a class that represents a collection and provides an interface for interacting with the database. Models are created from schemas.

// Create a model from the schema
const User = mongoose.model('User', userSchema);
const Product = mongoose.model('Product', productSchema);

// Now you can perform CRUD operations
// Create a new user
const newUser = new User({
  name: 'John Doe',
  email: 'john@example.com',
  age: 25
});

// Save to database
await newUser.save();

// Or use create method
const user = await User.create({
  name: 'Jane Doe',
  email: 'jane@example.com'
});
✅ Model names are automatically pluralized to form collection names (User → users).

Building Insert (POST) API

Let's create a POST endpoint to insert data into MongoDB using Mongoose.

const express = require('express');
const mongoose = require('mongoose');
const router = express.Router();
const User = require('../models/User');

// POST /api/users - Create a new user
router.post('/users', async (req, res) => {
  try {
    const { name, email, age } = req.body;

    // Validate required fields
    if (!name || !email) {
      return res.status(400).json({
        error: 'Name and email are required'
      });
    }

    // Check if user already exists
    const existingUser = await User.findOne({ email });
    if (existingUser) {
      return res.status(409).json({
        error: 'User with this email already exists'
      });
    }

    // Create new user
    const user = new User({ name, email, age });
    await user.save();

    res.status(201).json({
      success: true,
      data: user,
      message: 'User created successfully'
    });
  } catch (error) {
    console.error('Error creating user:', error);
    res.status(500).json({
      error: 'Internal server error',
      details: error.message
    });
  }
});

Building Fetch (GET) API - All Records

GET endpoint to fetch all users from the database with filtering, sorting, and pagination support.

// GET /api/users - Fetch all users
router.get('/users', async (req, res) => {
  try {
    const { page = 1, limit = 10, sortBy = 'createdAt', sortOrder = 'desc', search } = req.query;

    // Build filter object
    const filter = {};
    if (search) {
      filter.$or = [
        { name: { $regex: search, $options: 'i' } },
        { email: { $regex: search, $options: 'i' } }
      ];
    }

    // Fetch users with pagination
    const skip = (parseInt(page) - 1) * parseInt(limit);
    const sort = {};
    sort[sortBy] = sortOrder === 'desc' ? -1 : 1;

    const users = await User.find(filter)
      .sort(sort)
      .skip(skip)
      .limit(parseInt(limit))
      .select('-__v'); // Exclude version field

    const total = await User.countDocuments(filter);

    res.json({
      success: true,
      data: users,
      pagination: {
        page: parseInt(page),
        limit: parseInt(limit),
        total,
        pages: Math.ceil(total / parseInt(limit))
      }
    });
  } catch (error) {
    console.error('Error fetching users:', error);
    res.status(500).json({
      error: 'Internal server error'
    });
  }
});

Building Fetch API - Get by ID

GET endpoint to fetch a single user by their ID.

// GET /api/users/:id - Fetch a single user
router.get('/users/:id', async (req, res) => {
  try {
    const { id } = req.params;

    // Validate ObjectId format
    if (!mongoose.Types.ObjectId.isValid(id)) {
      return res.status(400).json({
        error: 'Invalid user ID format'
      });
    }

    const user = await User.findById(id).select('-__v');

    if (!user) {
      return res.status(404).json({
        error: 'User not found'
      });
    }

    res.json({
      success: true,
      data: user
    });
  } catch (error) {
    console.error('Error fetching user:', error);
    res.status(500).json({
      error: 'Internal server error'
    });
  }
});
✅ Always validate ObjectId format before querying to prevent errors.

Building Update (PUT) API

PUT endpoint to update an existing user.

// PUT /api/users/:id - Update a user
router.put('/users/:id', async (req, res) => {
  try {
    const { id } = req.params;
    const { name, email, age, isActive } = req.body;

    // Validate ObjectId
    if (!mongoose.Types.ObjectId.isValid(id)) {
      return res.status(400).json({ error: 'Invalid user ID' });
    }

    // Check if email is being changed and already exists
    if (email) {
      const existingUser = await User.findOne({ email, _id: { $ne: id } });
      if (existingUser) {
        return res.status(409).json({
          error: 'Email already in use'
        });
      }
    }

    // Find and update
    const user = await User.findByIdAndUpdate(
      id,
      { name, email, age, isActive },
      {
        new: true, // Return updated document
        runValidators: true // Run schema validations
      }
    ).select('-__v');

    if (!user) {
      return res.status(404).json({ error: 'User not found' });
    }

    res.json({
      success: true,
      data: user,
      message: 'User updated successfully'
    });
  } catch (error) {
    console.error('Error updating user:', error);
    res.status(500).json({ error: 'Internal server error' });
  }
});

Building Delete (DELETE) API

DELETE endpoint to remove a user from the database.

// DELETE /api/users/:id - Delete a user
router.delete('/users/:id', async (req, res) => {
  try {
    const { id } = req.params;

    // Validate ObjectId
    if (!mongoose.Types.ObjectId.isValid(id)) {
      return res.status(400).json({ error: 'Invalid user ID' });
    }

    const user = await User.findByIdAndDelete(id);

    if (!user) {
      return res.status(404).json({ error: 'User not found' });
    }

    res.json({
      success: true,
      message: 'User deleted successfully',
      data: user
    });
  } catch (error) {
    console.error('Error deleting user:', error);
    res.status(500).json({ error: 'Internal server error' });
  }
});
